# EduTask – Student Task Manager

EduTask is a simple mobile application developed
using Flutter and Dart as part of my internship
project. It is designed to help students add and
manage their academic tasks through a simple
interface.

## Features
- Add new academic tasks
- Enter task details
- Select a due date
- Set task priority (if available)

## Technologies Used
- Flutter
- Dart
- Android
