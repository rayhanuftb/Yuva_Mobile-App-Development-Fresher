# 📝 EduTask

## Student Task Manager

EduTask is a simple and modern mobile application developed using Flutter and Dart. The application helps students add and organize their academic tasks.

Users can create a task by providing a task title, description, due date, and priority level.

The application has a clean and user-friendly interface designed for easy task management.

---

## 📱 Features

- ➕ Add New Task
- 📝 Task Title
- 📄 Task Description
- 📅 Select Due Date
- 🚩 Set Task Priority
- 💾 Save Task
- 📊 Task Statistics
  - Total Tasks
  - Completed Tasks
  - Pending Tasks

---

## 🛠️ Technology Used

- Flutter
- Dart
- SharedPreferences
